# 动态图集

## 定位与边界

本模块属于 B_Assets 为运行时散图提供 GPU 合图 多页管理 引用句柄与整页回收
固定 UI 图标优先使用静态 SpriteAtlas 动态图集不是离线打包器

- Runtime 只依赖 UniTask 与 Unity 不依赖 UI YooAsset 或 ModuleHub
- Adapters/YooAsset 对接现有 YooAssetMgr 默认包 不创建第二套资源加载管理器
- Editor 仅 Editor 平台 用于配置绑定 运行时观察与纹理试装
- Shaders 提供格式转换与边缘像素扩展 通过配置资产显式引用 防止构建剥离
- 不修改 FrameRoot Prefab 场景 ModuleHub 初始化顺序或已有程序集

## 快速接入

1. 复制 Config/DefaultDynamicAtlasConfig.asset 为业务配置 或通过 Create → MieMieFramework → 资源 → 动态图集配置创建
   本工程已提供一份带 Shader 引用的业务配置 位置见 [默认资源](../../../../../ADefaultRes/README.md)
2. 新配置在 Inspector 点击 绑定内置 Shader 默认配置已绑定
3. 在需要持有图集组的 GameObject 上添加 DynamicAtlasHost 并指定配置
4. Host 的 Start 是唯一 InitComponents 入口 OnDestroy 取消加载并释放资源
5. 等 Host.IsInitialized 为 true 后访问 Host.Service 不依赖多个组件 Start 的执行顺序
6. 使用 YooAsset 加载时还须等待现有 YooAsset 启动就绪
7. 消费者清除 Image.sprite 或 RawImage.texture 后 Dispose 自己持有的图集句柄
8. 一个窗口关闭后可调用 TrimUnusedPages 回收所有整页零引用缓存

也可由一个明确的业务所有者直接 new DynamicAtlasService(config) 并在对应退出入口 Dispose
两种所有者方式择一 不让 Host 与业务同时负责 Dispose 同一服务

## API

| 入口 | 契约 |
| --- | --- |
| Acquire(key texture) | 主线程同步合图 输入 Texture2D 只借用 不销毁源纹理 返回新使用句柄 |
| LoadAsync(key loader token) | 主线程开始 同键合并在途请求 成功后每个消费者取得独立句柄 |
| DynamicAtlasHandle.Sprite | 共享 Sprite 不得由业务直接 Destroy 释放句柄后不得继续使用 |
| DynamicAtlasHandle.Uv | 给 RawImage 使用的内容 UV 不含边缘扩展 |
| DynamicAtlasHandle.Dispose | 只归还本消费者引用 重复调用不重复扣减 |
| TrimUnusedPages | 仅回收发布事务已结束且引用与等待者均为零的页 返回回收页数 |
| GetPageInfoList | 只读调试快照 包含分配占用 引用数 等待数 不建议业务逐帧调用 |
| DynamicAtlasService.Dispose | 失效所有句柄 取消请求 销毁页内 Sprite 页纹理与写入材质 |

资源键是一个图集组内不可变的内容标识 相同 key 必须指向相同图片
同键并发加载必须传入同一个 loader 实例 同键缓存命中直接返回已有内容
远程图片使用包含来源与版本的键 不要用一个 key 覆盖不断变化的内容
默认包 YooAsset 加载键须为可加载 Texture2D 的 location 不支持 Sprite 子资源键

```csharp
var Loader = new YooAssetDynamicAtlasLoader();
var Handle = await Host.Service.LoadAsync(Location, Loader, CancellationToken);
Image.sprite = Handle.Sprite;
```

Handle 必须作为消费者实例字段保留 使用期间不要放在立即结束的 using 中
消费者结束使用时先清除 UI 对 Sprite 的引用 再调用 Handle.Dispose
RawImage 设置 Handle.Sprite.texture 与 Handle.Uv 同样遵循句柄生命周期
外部下载得到的 Texture2D 可直接 Acquire 合图完成后由下载资源所有者释放原图

## 分配与预算

- 算法 Skyline 只追加 不旋转 不实时重排 不回收单个矩形
- 优先分配现有页剩余空间 满页新增 达页数或预算上限时回收零引用页
- 全部页仍有使用引用时立即抛出包含 key 尺寸 页数与预算的异常 不回退到散图
- 单图内容尺寸加两侧 padding 必须放入一页 不自动缩放 不跨页切图
- RGBA32 无 MipMap Bilinear 采样 Clamp 地址模式 输出 FullRect Sprite
- 每个图集组共享一个 Pivot 与 PixelsPerUnit Border 固定为零 不支持原 Sprite 的旋转 裁切 九宫格与特殊网格元数据
- 配置在服务构造时快照化 Play Mode 修改资产不会改变已创建的服务
- 默认页 1024×1024 Padding 2 最大 8 页 纹理逻辑常驻预算 32 MiB
- ResidentBytes 按页宽×页高×4 统计 不含源纹理 材质 临时 RT Unity 分配开销与延迟销毁峰值
- 源加载只做同键去重 没有跨键并发限流 下载并发与源图预算由加载器或上层控制
- 释放一个句柄不会擦除像素或移动内容 零引用条目可继续缓存 直到页回收或服务销毁
- 活跃 Sprite 的纹理 UV 不随新增图片变化

## GPU 与取消

源纹理无需 Read/Write 开启 Shader 在 GPU 采样源格式并扩展边缘 临时 RT 使用与图集一致的 graphicsFormat
初始化后图集没有 CPU 像素副本 更新只走 GPU CopyTexture 不使用 GetPixels ReadPixels SetPixels 或 Apply
设备必须支持 RGBA32 渲染采样与 RTToTexture 复制 不支持时初始化失败 不静默换 CPU 路径
源纹理必须是二维颜色图片 sRGB 配置决定目标存储色彩空间 线性数据图须使用独立配置

取消一个等待者不影响其他等待者 最后一个等待者退出后取消共享源加载并移除在途索引
加载器须响应传入 token 未响应取消的加载结果到达后仍会释放源所有权 但不会写入已取消或销毁的服务
加载器成功返回 DynamicAtlasSource 后所有权交给服务 加载器抛错前须自行释放尚未转交的资源
源所有权在合图完成或失败时释放 一份合并加载只释放一次源资源
源所有权释放成功后才正式发布缓存 释放回调重入同键同步 Acquire 时拒绝获取尚未完成的条目
未完成的发布事务始终保护所在页 即便最后一个等待者已取消也不能在源释放回调中回收该页
源释放抛出异常或取消异常时统一撤销未完成条目 回滚不删除同键新请求或替代条目
销毁 Host 是图集组终止边界 必须先让业务消费者退出 不支持销毁后继续展示已取得的 Sprite

## Editor 调试

菜单 Tools → MieMieFrameWork → 工具中枢 → 资源 → 动态图集调试

- Play Mode 拖入已初始化 Host 或观察当前选中对象的图集组
- 查看页数 待加载 逻辑常驻预算 纹理预览 分配占用与条目引用
- 绿色边线为活跃引用 黄色边线为零引用缓存 坐标包含边缘扩展
- 选择已导入 Texture2D 试装 可多次获取同图观察共享与引用增加
- 释放窗口试装引用只处理窗口自己的句柄 不清理业务句柄
- 回收按钮只回收整页零引用页 不强制销毁活跃页
- 快照刷新间隔 0.5 秒 窗口关闭 脚本重载和退出 Play Mode 时归还窗口引用

## 手工验收

1. 同图试装两次 应只出现一个条目且引用为 2
2. 保留引用时点回收不应销毁所在页 释放窗口引用后回收应销毁整页
3. 小页配置试装多张不同图片 满页扩页 保留所有引用时达到上限应明确报错
4. 在背景明暗变化和缩放时检查透明边缘与相邻图块 不应出现串色
5. 实际业务完成一次 YooAsset 加载 窗口关闭 场景切换 加载中销毁与重复进入
6. 使用 Memory Profiler 与目标平台验证释放延迟峰值 使用 Frame Debugger 比较真实 UI 批次
